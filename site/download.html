Install

  1. Open the downloaded file, {{installerName}}.
  2. Windows may show "Windows protected your PC" because the installer is new and not yet widely downloaded. Click More info, then Run anyway. Check the file's SHA-256 above if you want to be sure it's ours.
  3. Follow the installer. It installs for your Windows user only and doesn't need administrator rights.
  4. Open {{name}} from the Start menu or the desktop.

Two windows open: the control panel, and a small black log window (minimised). Keep the log window open while you use {{name}}. Closing the control panel quits the app.

Updating

The app tells you when a new version is out. Download it here and run it over the old one; your settings, logs and subscription stay.

Uninstalling

Windows Settings → Apps → Installed apps → {{name}} → Uninstall. Your data (settings, bet logs, the casino login of the game window, and your license) stays in %LOCALAPPDATA%\{{name}} in case you reinstall; delete that folder to remove it.
